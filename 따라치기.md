# 따라치기

1장부터 9장까지 쓸 코드를 모았다.
1~3장은 3장 끝 파일을 통째로 준다.
4장부터는 단계마다 바뀌는 코드를 준다.

## 준비

- server-node를 8080 포트로 띄운다 (5장부터 필요)
- 이 폴더에서 npm install
- npm run dev
- 브라우저로 http://localhost:5173
- 라이브러리는 package.json에 이미 들어 있다

## 읽는 법

- 파일과 새 파일은 코드 전체를 그대로 넣는다. 있던 파일이면 덮어쓴다
- diff 블록에서 + 줄은 더하고 - 줄은 지운다
- 앞에 기호가 없는 줄은 위치를 찾는 데 쓰고 그대로 둔다

## 1~3장 출발점, 레이아웃, 화면

3장 끝 파일을 통째로 넣는다.
아래 순서대로 넣으면 App.jsx를 넣을 때 화면이 뜬다.
