# 따라치기

1장부터 9장까지 코드를 순서대로 따라 친다.
1~3장은 이 저장소에 이미 들어 있다.
4장부터 이어서 친다.

## 준비

- server-node를 8080 포트로 띄운다 (5장부터 필요)
- 이 폴더에서 npm install
- npm run dev
- 브라우저로 http://localhost:5173
- 라이브러리는 package.json에 이미 들어 있다

## 읽는 법

- 새 파일은 코드 전체를 그대로 친다
- diff 블록에서 + 줄은 더하고 - 줄은 지운다
- 앞에 기호가 없는 줄은 위치를 찾는 데 쓰고 그대로 둔다
- 한 단계를 치면 화면을 확인하고 다음 단계로 간다
